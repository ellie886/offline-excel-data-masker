# 离线 Excel 数据脱敏工具

一款面向投行、审计、财务和尽调场景的本地 Excel 数据脱敏工具。界面运行在 `127.0.0.1`，文件不会发送到外部服务器，也不调用云端 API。

## 当前 MVP

支持：

- 单个未加密、无宏、无数字签名的 `.xlsx` 文件；
- 手机号、18 位身份证号和邮箱规则检测；
- 用户指定列中的客户、供应商、人员、企业、地址、合同编号和文本型银行账号；
- 自定义敏感词；
- 掩码、一致性编号和自定义替换；
- 默认安全预览和人工确认；
- 隐藏工作表、隐藏行列及普通批注风险提示；
- 公式、数值常量、样式引用、合并区域、隐藏状态、冻结窗格、筛选和打印设置校验；
- 独立的脱敏及校验报告。

暂不支持：

- `.xls`、`.xlsm`、`.xlsb`、CSV；
- 密码保护、加密或带数字签名的文件；
- 修改金额、数量、单价、税额、比例和公式；
- 扫描文本框、形状、图表、线程批注、嵌入对象及外部连接内容；
- 持久化保存原值与脱敏值映射；
- 通用本地 NER、批量文件处理和桌面安装包。

## 为什么采用 OOXML 定点修改

核心处理器不会用 `openpyxl` 整体保存用户工作簿。程序只修改已确认单元格所在的工作表 XML，并原样复制其他 OOXML 组件。目标单元格会转换为普通内联字符串，样式引用保持不变。

处理后程序会重新打开输出文件，并比较：

- 工作表名称、顺序、范围和隐藏状态；
- 公式数量与公式文本；
- 所有非目标数值常量；
- 单元格样式引用和合并区域；
- 冻结窗格、筛选、打印设置和行列设置；
- 非目标 OOXML 组件的原始字节；
- 实际替换数量及目标单元格最终内容。

任何关键校验失败时，界面不会提供脱敏工作簿下载，只提供失败校验报告。

## 本地运行

推荐使用 Python 3.12 和 `uv`：

```bash
uv venv --python 3.12
uv sync --extra dev
uv run streamlit run app.py
```

浏览器打开 `http://127.0.0.1:8501`。首次安装依赖可能需要联网；依赖安装完成后，核心运行流程可以断网完成。

也可以使用传统虚拟环境：

```bash
python3.12 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

不要把应用改为监听 `0.0.0.0`，也不要部署到 Streamlit Cloud 后处理真实敏感文件。

## 测试

```bash
uv run pytest
```

不依赖 pytest 时也可运行标准库测试：

```bash
PYTHONPATH=src python -m unittest discover -s tests -v
```

测试工作簿在内存中生成，不会创建或提交真实敏感样例文件。

## 目录说明

- `app.py`：四步式 Streamlit 界面；
- `src/offline_masker/security`：输入文件防护和安全预览；
- `src/offline_masker/detectors`：规则、表头、指定列及自定义词检测；
- `src/offline_masker/maskers`：掩码、内存映射和替换计划；
- `src/offline_masker/excel`：工作簿检查与 OOXML 定点修改；
- `src/offline_masker/validation`：处理后校验；
- `src/offline_masker/reports`：本地审计报告；
- `tests`：单元测试和端到端保真测试。

## 安全说明

- 映射表只存在于当前 Python 进程内存中，处理结束即清空；
- 运行日志不记录原始单元格内容；
- 报告仅保留安全预览、单元格位置和不可逆短指纹；
- 原文件不会被覆盖；
- 浏览器扩展、本机恶意软件和操作系统层面的风险不属于本工具能够隔离的范围。
